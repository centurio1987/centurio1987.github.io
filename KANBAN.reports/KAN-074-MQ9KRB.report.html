드리프트 608 은 공짜다 — 그리고 그것이 부채의 78% 다

608건이 가리키는 토큰은 12종뿐이고 전부 고정 px 이다(tokens.css:151-155,187-198,222-228). --text-display·--text-h1 만 clamp() 인데 그 둘은 608건 중 한 건도 안 쓴다. 그래서 borderRadius: 8 → borderRadius: "var(--radius-sm)" 는 계산값이 바이트 단위로 같다.

값 뭉치는 13px137 · 8px117(radius 72 + spacing 45) · 12px104(spacing 59 + font 45) · 14px55 · 10px50 · 6px41 순이고, 앞 셋만으로 358건(59%)이다.

고장 나는 길이 하나뿐이다. var(--x) 가 안 풀리면(오타·범위 밖) 그 선언이 통째로 무효가 되어 속성이 떨어진다. 값이 *틀리게* 바뀌는 경로는 없다 — 치환기가 「토큰 값 ≠ 리터럴 값」이면 거부하기 때문이다. 그래서 검증은 스크린샷 눈대중이 아니라 getComputedStyle 전수 대조 하나로 닫힌다. 이 성질 때문에 드리프트는 코드모드로 일괄 치환하고 손으로 안 고친다.

여기서 선례가 이미 답한 것과 새로 물을 것이 갈린다. #e5f0ed 6건은 KAN-072 S13 이 --cat-skills 11% color-mix 로 이미 판정한 값인데 삼항 안에 있어 그때 게이트 시야 밖이었다 — 새 판정이 아니라 같은 판정의 적용이다. #a9a294 는 반대로 KAN-072 S13 이 "그 단이 토큰에 없다"로 남기기로 판정한 자리다. 새로 물어야 하는 것은 기하 뭉치 셋이다(18px 29건 · 6px 28건 · 반픽셀 글자 34건).

왜 이 순서인가 — 드리프트 먼저

셋 다 같은 이유를 가리킨다.

  1. 78% 를 화면 변화 0 으로 먼저 닫는다. 래칫이 778 → 170 으로 떨어지고, 남은 것이 전부 "판정이 필요한 것"만 된다. 되돌릴 일이 생겨도 되돌릴 대상이 명확하다.
  2. 위반 판정의 재료가 정확해진다. 드리프트가 섞여 있으면 "이 파일에서 화면이 바뀌었다"의 원인이 둘이라 대조가 흐려진다. 드리프트를 먼저 닫아 두면 그 뒤 화면 변화는 전부 스냅 때문이다.
  3. 하네스를 싼 데서 먼저 시험한다. 화면이 안 바뀌어야 하는 구간에서 하네스가 "안 바뀌었다"를 내면 그건 하네스가 죽었다는 뜻일 수도 있다 — 그래서 S1 이 고장을 주입해 무는지부터 본다.

하네스를 이번엔 커밋한다

KAN-072 의 대조 하네스는 스크래치패드에만 있었고 세션과 함께 사라졌다. 이 카드가 그것을 다시 짓고 있고, KAN-075·076·077 이 또 같은 것을 지어야 한다. 세 번 다시 짓는 값이 스크립트 한 장을 두는 값보다 크다. 게이트가 아니라 개발 도구이므로 CI 에 안 물린다.

하네스가 조용히 통과하는 고장 셋(KANBAN.cards/KAN-072-CPJCT1.md:229, 전부 실측)을 코드로 막고 자가검사로 확인한다.

  • [style*='hex'] 로 세면 안 된다 — React 는 재렌더 때 인라인 hex 를 rgb() 로 정규화해서 조작이 건드린 노드만 골라 셀렉터에서 빠진다. 결과가 "0곳, 이상 없음"으로 나온다.
  • 셀렉터에 리터럴을 박으면 치환 후 조용히 0 이 된다([style*='2px solid']).
  • 0건 통과를 그냥 믿지 않는다 — 고장을 주입해 무는지 먼저 본다. 주입은 두 갈래여야 한다: 토큰 이름을 지우면 이름 감사만 물고(fallback 이 같아 화면은 안 바뀐다), 값을 지역에서 뒤집으면 화면 대조만 문다.

격리 사본의 함정 일곱도 같은 자리에 기록돼 있다 — rsync -a --link-dest(심링크 node_modules 로는 vite 가 없는 경로를 만든다) · --exclude '/dist'(앵커 없으면 node_modules/astro/dist 까지 지운다) · sed -E 's/ uid="[^"]*"//g'(안 지우면 46쪽 중 26쪽이 달라졌다고 나온다) · git show HEAD:<경로>(공유 인덱스를 안 건드린다) · astro preview 는 [::1] 바인딩이라 localhost 로 붙는다 · width:verify --base 는 outDir 이 아니라 URL · 사본을 레포 안에 두면 tsc 가 두 벌로 훑는다.
