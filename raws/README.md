# raws/

아이디어와 문장 파편의 집합. **사용자(김윤덕)가 직접 작성하는 공간**이다.

- 형식은 자유 — bullet 메모, 산문 조각, 인용, 링크 무엇이든.
- 한 주제당 한 파일을 권장하되 강제하지 않는다.
- 여기 적힌 내용을 토대로 `post-draft` 스킬이 `draft/`에 초안 골격(플롯 후보 + 주의사항)을 만든다.

## 워크플로우

```
raws/<메모>.md
  → post-draft  → draft/<메모>-draft.md  (플롯 3개 + 주의사항)
  → 플롯 선택 + 본문 작성
  → review-post (4축 검토)
  → post-finalize (이미지·태그·시리즈)
  → publish-post → src/content/posts/<글>.md
```
