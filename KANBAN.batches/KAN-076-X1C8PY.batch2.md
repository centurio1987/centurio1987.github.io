## 1. 작업 패키지

### WP1 · `S4` 자가검사 — 인식기가 자기 고장을 소유한다

`svgStroke.faults` 와 픽스처를 함께 만든다. 규약은 `recognize/types.ts` 그대로 —
유일성 키가 `(판정, 사유, 인식 경로)` 셋이라 사유가 다른 갈래와 겹쳐도 된다.

고장 **둘**을 심는다. 둘로 나누는 이유가 있다 — 이 갈래는 실제 레포에서 거의 전부
`판정 불가` 로 떨어지는데, **`판정 불가` 는 자가검사가 안 본다**(②가 찾는 것이
`위반`·`드리프트` 계열 사유다). 인식기가 통째로 죽어도 ①만으로는 안 울 수 있다.

1. **px 자리의 토큰 밖 굵기** → `위반 / stroke 축 / svg-stroke`
   픽스처는 **viewBox 없는 `<svg>`** 에 `stroke-width="7"` 을 둔다. 그 자리는 1단위 = 1px
   이라 `--stroke*` 3단(1·1.5·2px) 밖이다. 이 고장이 **판정 규칙 전체를 지킨다** —
   좌표계 판별이 거꾸로 되면(미상을 px 로) 이 검사가 통과하면서 실제 레포가 가짜 위반으로
   뒤덮이므로, 아래 2번이 반대쪽을 잡는다.
2. **사용자 단위 자리가 인식은 되는가** → `판정 불가 / stroke 축` + 좌표계 문자열
   픽스처는 viewBox 있는 `<svg>` 에 `stroke-width="9"`. 자가검사 ②는 사유 조각을
   `includes` 로 보므로 「사용자 단위」를 사유에 넣으면 `판정 불가` 도 그대로 검사가 된다.
   **인식기가 죽으면 이 검사가 먼저 운다.**

**완료 기준**: `bun run tokens:verify` 의 자가검사 줄이 **고장 12종 · 사유 12가지**
(현재 10·10)로 늘고, 종료 0. 그리고 **죽여서 확인한다** — `extract.ts` 의 `RECOGNIZERS`
배열에서 `svgStroke` 를 빼면 자가검사가 빨개져야 한다. 안 빨개지면 그 고장은 있어 보이기만
하는 검사이고, 그때는 지운다(KAN-075 가 가드 하나를 그렇게 지웠다).

### WP2 · `S5` 불변 증명 + 기준선 갱신 — **같은 커밋에서**

```
bun run tokens:invariant -- --before /tmp/kan076-before.json --self-test
bun run tokens:verify -- --update-baseline
```

- 하네스가 보는 셋: ① 기준 커밋 스냅샷 대비 **옛 판정 불변** ② 새·옛 인식 경로가 같은
  자리를 겹쳐 세지 않음 ③ 겹침 가드 자가검사.
- ①이 무는 것은 판정(`verdicts`)이지 히트가 아니다 — 히트가 그대로여도 축 모듈이
  다르게 부르기 시작하면 감사 원자료와의 대조는 똑같이 깨진다.
- **기준선 갱신을 다음 커밋으로 미루지 않는다.** 인식층을 넓힌 커밋과 기준선이 갈리면
  그 사이 푸시에서 게이트가 빨개지고, CI 는 `build` 잡 안에서 `astro build` 앞에 이것을
  돌리며 `deploy` 가 `needs: build` 라 **사이트 배포가 멈춘다.**

**완료 기준**: `tokens:invariant` 종료 0 (옛 히트 증분 0 · 겹침 0) ·
`tokens:verify` 종료 0 · `bun run build` 종료 0 · `git diff --stat -- src/` 빈 출력.

## 2. 의존과 순서

WP1 → WP2. WP1 이 먼저인 이유는 `--update-baseline` 이 **자가검사를 지난 뒤의 수**를
박아야 하기 때문이다 — 고장이 안 걸리는 상태로 박은 기준선은 죽은 게이트의 기준선이다.

배치1 이 뜬 스냅샷(`/tmp/kan076-before.json`)이 이 배치의 입력이다. **없으면 만들지 말고
멈춘다** — 지금 상태로 다시 뜨면 이 카드의 변경이 이미 섞여 「옛 히트 불변」이 자기 자신과의
비교가 된다. 그때는 기준 커밋을 `git stash` 로 되돌려 다시 뜬다.

## 3. 리스크

- **스냅샷 유실.** `/tmp` 는 세션 밖에서 사라진다. 배치1 이 뜬 것을 배치2 에서 못 찾으면
  위처럼 `git stash` 경유로 다시 뜬다 — 그것이 유일하게 맞는 복구다.
- **자가검사가 통과하는데 인식기가 죽어 있는 경우.** WP1 의 「죽여서 확인」이 그것을
  판정한다. 이 절차를 생략하면 고장 둘이 다른 검사가 잡고 있어도 모른다.
- **기준선이 예상보다 크게 움직이는 경우.** `판정 불가` 만 늘어야 한다. `위반`·`드리프트`가
  한 건이라도 늘면 그것은 좌표계 판별이 거꾸로 된 신호다 — 기준선을 올려 넘어가지 말고
  배치1 의 WP2 로 되돌아간다.
