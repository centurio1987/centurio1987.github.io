# KAN-076-X1C8PY 배치3 — 갈림선을 코드 밖에도 적는다

카드: [KAN-076-X1C8PY.md](../KANBAN.cards/KAN-076-X1C8PY.md) · 범위 `S6` · `S7`
선행: 배치2 (`S4`·`S5`)

> **이 문서는 착수 전 계획이다.** 수행 내역은 카드 실행 문서의 「수행 내역」에 있다.

## 1. 작업 패키지

### WP1 · `S6` 문서 셋

카드의 목표가 「그 갈림선이 **코드와 문서에** 적힌다」이므로 이 WP 가 목표의 절반이다.

1. **`design-concept/UI_CONSISTENCY_AUDIT.md` §6-12 에 정정 블록.**
   KAN-075 가 §6-11 에 단 것과 **같은 형식**(`> **정정 (KAN-076, 2026-08-30).**`)으로,
   ① 「viewBox 유무가 갈림선」이 실측과 안 맞는다는 것 — 범위 안 자리는 전부 viewBox
   안에 있고 viewBox 없는 SVG 가 0개다, ② 카드가 든 예시 둘이 틀렸다는 것과 그 근거
   (`Doodle.astro:437` 은 5.23px 또는 9px · `GraphExplorer` 는 `viewBox={\`0 0 ${W} ${H}\`}`
   + CSS `width:100%`), ③ 건수 정정(81 은 범위 밖 `.ts` 35 를 섞은 수 — 범위 안은 50),
   ④ 다시 쓴 갈림선(「이 길이의 단위가 CSS px 인가」)과 그래서 전부 `판정 불가` 라는 것.
   **§0 표는 안 건드린다** — 「기록이지 장부가 아니다」로 이미 동결됐다.
2. **`design-concept/DESIGN_CONCEPT.md` §8 선 굵기 절에 한 문단.**
   3단이 **CSS px 자**이고 SVG 좌표계 안의 `stroke-width` 는 그 관할 밖이라는 것,
   그리고 왜 그런지(배율을 호출자가 정한다) 한 줄. 이것이 없으면 다음 사람이
   `Mascot.astro` 의 `stroke-width="2.4"` 를 `--stroke-bold` 로 바꾸려 든다.
3. **`CLAUDE.md` 의 인식층 문단 갱신.** 「KAN-075 가 넷째를 열었다」를 다섯째까지로
   늘리고, 「아직 안 연 갈래가 **둘**」을 **하나**(KAN-077 상수 승격)로 고친다.
   승격 조건 문단의 「인식층이 다 열린 뒤의 래칫 0」은 그대로 둔다.

**완료 기준**: 세 문서에 각각 반영되고, **세 곳이 같은 수를 적는다.** 그 수는 문서에
박은 값이 아니라 `S3`·`S5` 가 낸 값이다 — CLAUDE.md 가 못박은 대로 **지금 무는 수는
문서에 안 적는다**(낡은 수는 최신인 얼굴로 틀린 규모를 말한다). 적는 것은 갈래와 규칙이다.

### WP2 · `S7` px 자리 부채 처분

`S3` 이후 `stroke` 축에서 무는 판정(위반·드리프트)이 실제로 나오는지 본다.

- **실측 예상은 0건이다** — px 자리(viewBox 없는 SVG)가 지금 레포에 하나도 없다.
- 0 이면 「0 임을 확인했다」를 수행 내역에 남기고 닫는다. 없는 부채를 만들어 갚지 않는다.
- 0 이 아니면 그 자리를 토큰으로 바꾸거나 근거 문서 위치와 함께 예외에 등록한다.
  **예외는 자리 단위(`site`)를 먼저 본다** — 파일 단위로 걸면 그 파일의 준수분과 다른
  축의 부채까지 통째로 판정에서 내려간다(KAN-074 가 정한 규약).
- 값을 실제로 고치게 되면 그때는 `bun run render:compare` 를 돌려 화면이 안 바뀌었음을
  증명하고, 카드 「검증」 절 표에 한 줄을 더한다.

**완료 기준**: `bun run tokens:verify` 의 `stroke` 축에 위반·드리프트가 0 이고,
그것이 「고쳐서 0」인지 「원래 0」인지가 수행 내역에 적혀 있다.

  위반으로 바꿔 「처분했다」로 만들지 않는다 — 그것이 정확히 이 카드가 막으려는 일이다.
