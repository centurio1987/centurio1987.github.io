## 전략
감사 정본 `design-concept/UI_CONSISTENCY_AUDIT.md:474` 의 **P4** 는 작업 항목이 아니라 결정이다 —
축 A(선언 층)를 A(채운다)·B(줄인다, 추천)·C(그대로) 중 무엇으로 처분할 것인가. KAN-069 검토서의

이 카드 브리프 셋이 전부 B안 문구를 그대로 옮겼다. 이 카드는 **B안의 실행**이다.

`bbangtoTonyStyleGuide.ts:138-139` 의 `bbangtoTonyStyleGuide`(`StyleGuide` 타입) export 는
**소비처가 0건**이다 — `StyleGuideProvider`(core) 사용처가 레포에 없고 import 하는 자리도 없다.
실제로 사는 것은 자매 export `bbangtoTonyFoundation` 하나이고 소비자도 하나다
(`scripts/gen-motion-css.ts:23,40` 이 `src/styles/motion.css` 를 굽는다). 파일 주석이 예고한
"아일랜드용 StyleGuideProvider(Phase C)"(`:5`)는 끝내 안 들어왔다.

그런데 그 안 쓰이는 선언이 `tokens.css` 값의 **두 번째 사본**을 들고 있고 셋이 어긋나 있다 —
`--btn-radius`(999↔9999px, `:101`) · `--font-body`(`:93`) · `--font-mono`(`:94`).

**감사가 안 적은 사실 하나 — 폰트 2건은 이미 화면에 살아 있다.** 같은 두 문자열이
`src/lib/viz/blogVizStyleGuide.ts:79-80` 에 글자 그대로 복제돼 있고 **그쪽은 실제로 주입된다**
(`VizFigure.tsx:128,130` · `render-viz.ts:70-71`). 감사가 "주입되는 순간 갈라진다"고 미래형으로
쓴 것이 viz 지면에서는 현재형이다. 그래서 scope 에 `blogVizStyleGuide.ts` 와 `render-viz.ts` 가 있다.

**유저 결정 3건(2026-08-28)**: ① 값은 두 파일 다 `tokens.css` 에 정렬 ② 주석 정합을
`.github/workflows/main.yml:60` 까지 밀고 scope 를 그만큼 넓힌다 ③ 착수는 인스턴트 예외 —
배치 문서·계획 리포트를 생략하고 이 문서만 채운 뒤 착수한다.

**`plan-reviewer` 검토 지적 1~10 을 반영한 판이다.** 지적 11(scope 에서 `gen-motion-css.ts`·
`render-viz.ts` 빼기)만 안 받았다 — 앞 파일이 이 변경의 핵심 전제를 지고 있어 읽기만 해도 범위에
남기는 쪽이 낫고, `dep-check` 판정에는 어느 쪽이든 영향이 없다(미완료 루트 14개 중 scope 가 있는
카드가 이것 하나뿐임을 실측했다).

**버린 대안**: A(층 다섯을 저작하고 주입) — 주입할 React 아일랜드가 셋뿐이라 지면 대부분에 효과가

## 검증
**순서가 규약이다. `build` 가 맨 앞이다** — `verify-viz.ts:123-125` 는 `dist/` 가 없으면
`"verify-viz: dist/ 가 없다. bun run build 를 먼저 돌려라."` 를 내고 `exit 2` 로 죽는다. 새 orca
워크트리에는 `dist/` 가 없으므로 순서를 바꾸면 무조건 실패하고, 남아 있더라도 그건 이번 변경이
안 들어간 옛 빌드다.

1. **빌드가 선다** — `bun run build` 통과(최근 실측 46쪽 — 고정값으로 박지 말고 실측을 남긴다).
2. **렌더 결과를 실측한다** — `diff -r <스크래치>/dist-before dist`(S0 사본과 대조).
   `blogVizStyleGuide` 변경의 **유일한 그물**이다. 차이가 나면 어느 글의 어느 그림인지 지목해
   수행 내역에 적는다. `git diff` 로는 안 보인다 — `dist` 는 `.gitignore:6` 로 무시되고, 로컬 viz
   kind 셋은 폰트를 값이 아니라 CSS 변수 참조로만 들고 있어(`ProcessSteps.tsx:134,146` ·
   `PosterHero.tsx:72-73` · `Comparison.tsx:128,151,207` 의 `vvar("typography","titleFont")`)
   소스도 안 바뀐다.
3. **viz 게이트** — `bun run viz:verify` 통과(최근 실측 43개). 폰트 메트릭이 곧 판정이므로 S0 과 대조.
4. **생성물이 안 흔들렸다** — `bun run gen:motion && git diff --exit-code -- src/styles/motion.css`.
   S0 에서 이미 diff 가 있었으면 패키지 버전 탓이고 S2 와 무관하다.
5. **토큰 게이트가 안 늘었다** — `bun run tokens:verify` 가 비0 으로 안 끝난다. 래칫은 "늘면 실패 /
   같으면 통과 / **줄면 통과 + 갱신 안내**"라(`verify-tokens.ts:18-19`) 기대값은 「기준선과 같다」가
   아니라 **「늘지 않는다」**다. 두 TS 파일은 확장자 때문에 스캔 대상이 아니므로(`extract.ts:74`)
   실제로는 카운트가 안 움직이는 것이 정상이다.
6. **심볼이 사라졌다** — `rg -n '\bbbangtoTonyStyleGuide\b' src scripts .github -g '!scripts/fixtures/**'`
   가 파일명 언급만 낸다. `bunx tsc --noEmit` 이 S0 의 기존 2건 외 새 에러 0건.
7. **회귀 없음** — `bun scripts/check-post-markers.ts` · `bun scripts/check-emphasis.ts`(+`--dist`) ·
   `bun scripts/check-quote-blocks.ts` · `bun run deco:verify` · `bun run width:verify` ·
   `bun run talk:verify` 전부 통과. **`bun run graph:verify` 는 착수 전부터 실패 중이다**(실행 계획
   S0 참고) — `src/data/`·`src/content/` 변경이 0건이면 이 카드와 무관하므로 카드 탓으로 읽지 않는다.

**`public/images/**/hero.webp`(27개)는 다시 굽지 않는다** — 재래스터는 이 카드 범위 밖이다.
글리프 단위 폴백 변화가 래스터에 미치는 영향은 검토 판단 항목으로 사람에게 올린다.
