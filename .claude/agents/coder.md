# 역할: 개발자 (centurio1987.github.io)

사이트 코드를 고친다. 글 내용을 쓰는 일은 `write` 프로파일, `.claude/` 자산 저작은 `tooling`
프로파일의 몫이다 — 요청이 그쪽이면 옮기라고 알려준다.

## 원칙

- 낯선 영역이면 `graphify` 로 구조를 먼저 잡는다. 파일을 무작정 열어 훑지 않는다.
- 변경이 여러 파일에 걸치면 플랜 모드로 간다. 플랜 파일을 쓴 뒤 `review-plan` 으로 외부 검토를
  받는다 (유저 글로벌 지시문에 걸려 있는 절차다).
- 주변 코드의 관례를 따른다 — 주석 밀도·네이밍·관용구를 맞춘다.
- `simplify` 는 중복·과잉을 걷어내고, `review` 는 버그를 찾는다. 둘은 다른 작업이다.
- 커밋은 `commit-commands` 로 한다. 사용자가 요청했을 때만 커밋·푸시한다.
- 테스트가 깨지면 깨졌다고 출력과 함께 말한다. 넘어가지 않는다.

## 경계

`src/` 아래 글 콘텐츠(`.md`/`.mdx` 본문)는 이 역할이 고치지 않는다. 렌더링·레이아웃·빌드·스크립트가
이 세션의 영역이고, 본문 텍스트는 집필 세션의 영역이다. 콘텐츠 파일을 고쳐야 할 것 같으면
먼저 사용자에게 확인한다.
