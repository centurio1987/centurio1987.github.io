# KAN-078-D44PD1 — render:compare 가 대조를 안 하고도 「전후 동일」이라고 답한다 — 거짓 통과를 막는다

## 전략
**고칠 것은 갈래가 아니라 결말이다.** 카드가 짚은 것은 `--self-test` 한 자리지만, 같은 형태를
파일 전체에서 세면 셋이다 — 종료 지점(`process.exit`)과 마지막 줄을 전수로 훑은 결과다.

| 자리 | 지금 끝나는 모양 | 무엇이 거짓인가 |
| --- | --- | --- |
| `scripts/compare-render.ts:667` `--self-test` 갈래 | 「✓ 전후 동일.」 · 종료코드 0 | 전후 대조를 **한 번도 안 했다.** KAN-077 S8 실측 |
| `:675` 변경 파일 0 | 「변경 파일이 없다」 · 0 | 문구는 정직한데 종료코드가 통과와 구분이 안 된다 |
| `:700` `--summary` | 요약표 · **차이가 있어도 0** | 파일 머리주석의 계약(「차이가 있으면 종료코드 1」)과 어긋난다 |

카드가 낸 갈래 후보 둘 중 **②(마지막 줄을 가른다)** 를 고르고, 그것을 저 셋 전체로 넓힌다.

①(자가검사 뒤에 실제 대조를 이어서 돈다)을 버린 이유 둘. ㉠ 자가검사는 사본 둘을 굽고
브라우저를 띄우는 데만 수 분이 걸린다 — 그 뒤에 실제 대조를 또 붙이면 「하네스가 아직 살아
있나」를 묻는 값싼 확인이 없어진다. ㉡ 그렇게 고쳐도 **마지막 줄은 여전히 갈래 공통**이라,
다음에 종료 갈래가 하나 더 생기면 같은 거짓이 그대로 다시 선다.

그래서 결말을 값 하나로 모은다. `verdict(mode, …)` 가 **무엇을 대조했는가(`compared`)** ·
**마지막 줄** · **종료코드** 셋을 함께 돌려주고 모든 경로가 그 표를 지나 끝난다. `compared`
가 거짓인 결말은 문구에 **「대조 안 함」을 반드시 담는다** — 통과 문구와 눈으로 구분되는 것이
이 카드의 산출물이다.

**자가검사는 값싸게 만들어 옵션과 무관하게 매 실행 돌린다.** 결말 판정은 빌드도 브라우저도
안 타므로 밀리초다. 네 가지를 본다 — ㉠ 모드마다 `compared` 가 맞는가 ㉡ `compared=false`
인데 「전후 동일」을 말하지 않는가 ㉢ **옛 결말(두 갈래 공통 한 줄)을 주입하면 무는가**
(카드가 청구한 재현이 이것이다) ㉣ 통과 문구의 생산 지점이 소스에 하나뿐인가(다시 흩어지면
표를 우회하는 길이 열린다). `--self-test` 뒤에 숨기지 않는 이유는 하나다 — 이 카드가 고치는
고장이 바로 **「자가검사를 돌렸다」와 「대조를 돌렸다」를 사람이 헷갈린 것**이라, 그 확인을
다시 옵션 뒤에 두면 같은 자리에 같은 함정을 판다.

**게이트가 아니다.** 이 도구는 CI 에 안 물린 개발 도구이고(파일 머리주석), 이 카드는 그
성질을 안 바꾼다. 래칫도 기준선도 안 만든다 — 늘고 줄 수가 없는 판정이다.

## 실행 계획
- [x] `S1` 결말을 `verdict()` 표 하나로 모은다 — 완료 기준: `--self-test` · 변경 파일 0 · `--summary` · 정상 대조 넷이 전부 그 표를 지나 끝나고, `compared=false` 인 셋의 마지막 줄에 「대조 안 함」이 들어간다. `--summary` 는 차이가 있으면 종료코드 1 로 끝나 머리주석 계약과 맞는다
- [x] `S2` 거짓 통과를 재현하는 자가검사를 붙인다 — 완료 기준: 옛 결말(갈래 공통 한 줄)을 주입한 사례가 **실패로 잡히고**, 통과 문구 생산 지점이 하나임을 소스에서 확인하며, 이 검사가 `--self-test` 없이도 매 실행 돈다
- [x] `S3` 실측으로 확인하고 문서를 맞춘다 — 완료 기준: `bun scripts/compare-render.ts --self-test` 의 마지막 줄에 「전후 동일」이 없고, 옵션 없는 실행이 종전대로 동작하며, 파일 머리주석과 `CLAUDE.md` 의 `render:compare` 절이 새 결말을 적는다

## 검증
전부 이 카드의 워크트리에서 돈다. `bun install` 이 먼저다(새 체크아웃이라 `node_modules` 가 없다).

```bash
# 1) 결말 자가검사 — 빌드·브라우저 없이 매 실행 첫머리에 돈다
bun scripts/compare-render.ts        # src/ 에 변경이 없는 상태
#   → 「결말 자가검사 … 통과」가 찍히고, 마지막 줄에 「대조 안 함」이 있다. 종료코드 0

# 2) 이 카드의 본론 — 자가검사만 돌린 실행이 「전후 동일」로 안 끝난다
bun scripts/compare-render.ts --self-test 2>&1 | tail -3
#   → 마지막 줄에 「전후 동일」이 없고 「대조 안 함」이 있다. 고장 4종 + 잡음 0 은 종전대로

# 3) 옛 결말을 주입하면 무는가 — (1)·(2) 어느 쪽을 돌려도 결말 자가검사가 그 사례를 함께 판정한다
#    일부러 깨서 보려면 verdict() 표의 selftest 행을 「✓ 전후 동일.」로 되돌린다 → 첫머리에서 종료코드 3

# 4) 정상 대조 경로가 그대로인가 — src/ 를 한 줄 고쳐 놓고
bun scripts/compare-render.ts --pages /posts/tauri-2/
#   → 차이가 있으면 종료코드 1, 없으면 「✓ 전후 동일」 + 0

# 5) 회귀 없음
bun run build && bunx tsc --noEmit
```

**판정 기준은 마지막 줄과 종료코드 둘 다다.** 문구만 고치고 종료코드를 안 가르면 스크립트로
부르는 쪽에서 같은 거짓이 그대로 남는다.
