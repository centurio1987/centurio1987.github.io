### KAN-050 — 포스트 우측 헤더 레벨 목차(TOC) 레일

#### Context

칸반 `KAN-050`(백로그): **"헤더 레벨로 포스트 페이지 우측에 네비게이션을 보여주고, 헤더를 클릭하면 바로 스크롤해서 이동할 수 있는 기능을 추가해라."**

이 블로그의 글은 길다 — 발행된 26편의 기술 글이 글당 h2 8~17개, h3 0~16개(최대 29항목)를 갖는다. 지금은 글 안에서 "지금 어디쯤이고 앞으로 뭐가 남았는지"를 알 방법이 본문을 스크롤하는 것뿐이다. 우측 여백에 헤딩 레벨 목차를 띄워 **글의 뼈대를 한눈에 보여주고, 클릭 한 번으로 해당 절로 점프**시킨다.

유리한 전제 — **본문 파일을 한 줄도 안 고쳐도 된다**:
- Astro의 `rehypeHeadingIds`가 `.md`/`.mdx` 모두에 heading `id`를 자동 부여한다(`@astrojs/markdown-remark`, `@astrojs/mdx` 양쪽 파이프라인에서 확인).
- `await render(post)`가 `headings: {depth, slug, text}[]`를 돌려준다. 이 `slug`는 **DOM에 실제로 박히는 그 `id`를 그대로 push한 값**이라(`rehype-collect-headings.js`) 링크와 앵커가 어긋날 수 없다 — 중복 제목 dedupe(`-1` 접미사)도 자동.
- `global.css`에 `html { scroll-behavior: smooth }` + reduced-motion 예외가 이미 있다. 헤더가 `position: sticky`라 `scroll-margin-top`만 얹으면 앵커 점프가 헤더에 가려지지 않는다.

#### 설계 결정 (사용자 확인 완료)

| 항목 | 결정 |
|---|---|
| 넓은 화면 배치 | 본문 720px 칼럼은 **페이지 정중앙 그대로**, 오른쪽 여백에 `position: fixed` 레일 (레이아웃 시프트 0) |
| 좁은 화면 | **숨김**(`display: none`). 데스크톱 전용 편의 기능 |
| 깊이 | **h2 + h3**, h3는 한 단 들여쓰기 + 작은 글씨 |
| 현재 위치 | **스크롤 스파이 포함** — 진행적 향상. JS 없거나 실패해도 순수 앵커 링크로 동작 |

대상은 `PostLayout`뿐이다. `TalkLayout`은 이미 자체 "오늘의 질문" 목차를 갖고 있고, 현재 `template: "talk"`를 쓰는 발행 글이 0편이다.

#### 구현

##### 1. `src/styles/tokens.css` — 헤더 높이 토큰

레이아웃 섹션에 `--header-h: 61px` 추가. 실측 근거를 주석으로 남긴다 — Header 패딩 14px×2 + 로고 아바타 32px(`Logo size={24}` × 1.35) + 보더 1px. **Header의 높이를 강제하는 값이 아니라 앵커 오프셋·레일 top의 참조값**이며, 어긋나도 3번의 스파이가 실측으로 덮어쓴다.

##### 2. `src/components/PostToc.astro` — 새 컴포넌트

```
Props: { headings: MarkdownHeading[] }   // render() 결과 그대로
```

- `depth === 2 || depth === 3`만 남기고, **2개 미만이면 아무것도 렌더하지 않는다**. 항목 1개짜리 목차는 정보가 0이지만 2개부터는 점프 가치가 있다(`welcome.md` h2 2개 → 레일 있음, `aside-arc.md`·`algorithm-at-40-prologue.md` 0개 → 없음).
- 마크업: `<nav class="post-toc" aria-label="이 글의 목차">` → `.toc-label`("목차 · CONTENTS", `--font-mono` 11px uppercase `--ink-3` — `TalkLayout`의 `.toc-label`과 같은 어법) + `<ul>` 평면 리스트, h3 항목에 `data-depth="3"`.
- 링크는 평범한 `<a href={"#" + slug} title={text}>`. **여기까지가 무JS 동작 전부다.** `title`은 2줄 클램프로 잘린 긴 제목의 전문을 보존한다.

스코프 스타일:
```css
.post-toc { display: none; }

/* 1320px: 본문 720 양옆 여백이 300px씩 → 24(간격) + 240(레일) = 264 ≤ 300.
   calc 에 100vw 를 쓰지 않는 이유 — min-width 미디어쿼리는 스크롤바를 제외한
   폭이고 100vw 는 포함이라 둘이 최대 15px 어긋난다(플랫폼·브라우저마다 다름).
   고정폭으로 두면 그 불일치 자체가 사라진다. */
@media (min-width: 1320px) {
  .post-toc {
    display: block;
    position: fixed;
    top: calc(var(--header-h) + 28px);
    left: calc(50% + var(--content-max) / 2 + 24px);
    width: 240px;
    max-height: calc(100vh - var(--header-h) - 72px);
    overflow-y: auto;
    overscroll-behavior: contain;
  }
}
@media print { .post-toc { display: none; } }
```
항목 스타일은 토큰만 쓴다 — 좌측 레일 보더 `1px solid var(--border)`, 항목 `border-left: 2px solid transparent`, 기본 `--ink-3` / hover `--ink` / `.is-active` `--accent` + 보더 채색, `transition: color var(--dur) var(--ease)`, 긴 제목 2줄 클램프, `:focus-visible` 아웃라인 명시(키보드 이동이 보여야 한다). `.prose a::after` 스케치 밑줄은 `.prose` 하위 전용이라 레일에 새지 않는다.

##### 3. `src/lib/motion/tocSpy.ts` — 스크롤 스파이 (신규)

`reveal.ts`의 **계약**(멱등·예외 시 조용히 폴백·리스너 1회 바인딩)은 따르되 **IntersectionObserver는 쓰지 않는다.** IO는 "1회 진입"에 맞는 도구고, 스파이는 연속 추적이라 활성값을 어차피 위치로 재계산해야 한다 — 그러면 IO는 트리거 역할만 남아 코드만 늘어난다.

- `scroll`·`resize`를 **passive** 리스너로 받아 `requestAnimationFrame` 1프레임 throttle. 헤딩은 최대 30개라 매 프레임 `getBoundingClientRect()` 훑기가 값싸다.
- 활성 판정: `top <= headerH + 8` 인 헤딩 중 **마지막**, 없으면 첫 번째. 활성 링크에 `aria-current="true"` + `.is-active`.
- **헤더 실측 → CSS 변수 갱신**: 초기화 때 `.site-header` 높이를 재서 `document.documentElement.style.setProperty("--header-h", h + "px")`. 토큰의 정적 61px은 무JS 폴백이 되고, 헤더가 폰트·패딩 변경으로 커져도 앵커 오프셋과 레일 top이 자동으로 따라간다.
- 레일이 넘칠 때 활성 항목을 **레일의 `scrollTop` 산술로** 보이게 한다 — `scrollIntoView()`는 페이지까지 끌고 갈 수 있어 쓰지 않는다.
- **teardown**: 매 초기화 시 이전 리스너·rAF를 먼저 해제한다. 목차나 헤딩이 없는 페이지(다른 글·홈)로 이동하면 그대로 해제 상태로 끝낸다 — 죽은 DOM을 붙잡고 매 스크롤 프레임을 도는 누수를 막는다.

`PostToc.astro` 하단 `<script>`에서 `initTocSpy(); document.addEventListener("astro:page-load", initTocSpy);` — `PostFilter.astro:331` 하단과 같은 패턴. ClientRouter가 켜져 있어 모듈 스크립트는 재실행되지 않으므로 이 재바인딩이 필수다. 컴포넌트 `<script>`이므로 번들은 이 컴포넌트를 쓰는 페이지에만 실린다(검증 4에서 확인).

##### 4. `src/layouts/PostLayout.astro`

- Props에 `headings: MarkdownHeading[]` 추가.
- `.post-header` 직후, `.prose` 앞에 `<PostToc headings={headings} />`. `position: fixed`라 시각 위치는 DOM 순서와 무관하고, **목차를 본문 앞에 두는 게 관례**다 — 키보드 사용자가 먼저 닿을 수 있고, `<nav aria-label>` 랜드마크라 스크린리더는 통째로 건너뛸 수 있다.
- 기존 `<style is:global>`의 `.prose` 블록에 앵커 오프셋 추가:
  ```css
  .prose :is(h2, h3) { scroll-margin-top: calc(var(--header-h) + 16px); }
  ```

##### 5. `src/pages/posts/[...slug].astro`

`const { Content, headings } = await render(post);` 로 바꾸고, 지금의 `const Layout = ...` 변수 분기 대신 **레이아웃별로 나눠 렌더**한다:

```astro
{post.data.template === "talk"
  ? <TalkLayout post={post}><Content /></TalkLayout>
  : <PostLayout post={post} headings={headings}><Content /></PostLayout>}
```

`TalkLayout`에 쓰지도 않을 옵셔널 prop을 얹어 타입만 넓히는 우회를 피한다.

#### 검증

```bash
bun run build && bun run preview
```
`file://`가 아니라 **preview(HTTP)** 로 본다(인라인 viz 페인트 규약과 같은 이유).

1. **레일 렌더**: `/posts/webrtc-2`(h2 13 + h3 16 = 29항목, 최악) · `/posts/vpn-anatomy-5`(h2 17, h3 0) → 레일 표시, 29항목에서 레일 내부만 스크롤되고 페이지는 안 움직인다.
2. **임계값**: `/posts/welcome`(2개) → 레일 있음. `/posts/aside-arc`(0개) → 레일 없음, 레이아웃 정상.
3. **앵커 전수 일치**(수동 세지 말 것): 빌드 산출물에서 목차 `href`와 헤딩 `id`가 1:1인지 한 방에 본다.
   ```bash
   # 각 글 HTML에서 .post-toc 의 href="#..." 목록과 본문 heading id 목록을 뽑아 차집합이 비는지
   grep -o 'class="post-toc"' -c dist/posts/webrtc-2/index.html   # 존재 확인
   ```
   차집합이 비지 않으면(고아 링크) 즉시 실패로 본다. 한글 slug·중복 제목(`-1` 접미사) 케이스가 여기서 같이 잡힌다.
4. **번들 격리**: 목차 스크립트가 `dist/posts/*/index.html`에만 실리고 `dist/index.html`·`dist/graph/index.html`에는 없는지 확인.
5. **폭**: 1440 / 1320 → 표시, 1319 / 1024 / 768 / 375 → 숨김. 어느 폭에서도 **가로 스크롤바가 생기지 않아야** 하고, 본문 칼럼 X좌표가 지금과 같은지(중앙 유지) 확인.
6. **점프**: 목차 항목 클릭 → 해당 헤딩이 sticky 헤더 아래에 여유를 두고 선다. 한글 slug 앵커도 동작.
7. **스파이**: 천천히 스크롤 → 활성 항목이 따라 이동, 섹션 경계·h3 구간·문서 최상단/최하단에서 하이라이트가 비지 않는다. 창 리사이즈 후에도 정확하다.
8. **View Transitions**: 글 → PostNav 이전화/다음화 이동 → 새 글에서 스파이가 다시 붙는다. 목차 없는 글(`aside-arc`)·홈으로 이동하면 스크롤 리스너가 해제된다(DevTools Event Listeners 탭에서 확인).
9. **폴백**: JS 비활성 → 목차가 그대로 보이고 클릭 점프도 된다(오프셋은 토큰의 61px 정적값). `prefers-reduced-motion: reduce` 에뮬레이션 → 스무스 없이 즉시 점프.
10. **회귀 없음**: 그래프 산출물(`graphify-out/`, `src/data/graph.json`)은 이 작업에서 건드리지 않는다 — `git status`로 확인.
